# Candlestick Analysis

Use this skill for `K线分析` / `蜡烛图分析` / `candlestick analysis`.

默认使用 **中文** 输出；术语保留 **中英双语**，例如：`锤子线 (Hammer)`、`吞没形态 (Engulfing)`、`启明星 (Morning Star)`。

本 skill 严格遵循日本蜡烛图技术的核心原则：**先看趋势，再看位置，再辨认形态，最后等确认**。单独的蜡烛线名称本身，不等于交易信号。

## 触发场景

适用于下列请求：
- “帮我做 K 线分析”
- “看这张蜡烛图”
- “这是不是反转形态”
- “识别锤子线 / 吞没 / 启明星 / 黄昏星”
- “根据这段 OHLC 判断走势”
- “给出确认位、失效位、止损位、目标位”

如果用户只提到某个术语、但不是在请求图表分析，避免强行套用本 skill。

## Step 1: 收集必要输入

优先确认以下信息：
- 标的：股票、指数、期货、外汇、加密货币等
- 周期：`5m / 15m / 1h / 4h / 日线 / 周线 / 月线`
- 输入形式：图像、OHLC 数据、或文字描述
- 观察窗口：至少最近 `30-100` 根 K 线
- 用户目标：识别形态、判断方向、制定交易计划、或多周期联判
- 如涉及持仓：成本价、仓位方向、止损约束、风险承受能力

如果信息不足，优先补这三项：
1. 时间周期
2. 最近一段完整走势
3. 关键价格区间或图像全貌

### 输入分流

**如果用户提供图像：**
- 先说明从图中能确认的周期、走势、关键位
- 若图像裁切过小或关键刻度不可见，明确说明结论只能暂定

**如果用户提供 OHLC 数据：**
- 先找近期高低点、支撑阻力、跳空窗口，再识别形态

**如果用户只提供文字描述：**
- 先把描述转成结构化判断，再说明结论可信度较低，最好补图或补数据

## Step 2: 先判断趋势与位置

任何形态都必须先放回它所处的趋势与位置中理解。

先回答：
- 当前是上升趋势、下降趋势、震荡区间，还是衰竭后的整理？
- 当前形态出现在高位、低位、支撑位、阻力位、缺口/窗口附近，还是区间中部？
- 高一级周期与当前周期是一致还是冲突？

优先关注以下位置因素：
- 前高 / 前低
- 水平支撑阻力
- 跳空窗口 (`Window / Gap`)
- 趋势线、通道边界
- 常见均线附近
- 密集成交区或整理区边缘

原则：**位置比形态名称更重要。**

## Step 3: 识别 K 线形态

只保留书中最常用、最有解释力的形态；识别后必须说明其成立条件与失效条件。

### 单根形态

**锤子线 (Hammer)**
- 含义：下降趋势后的潜在看涨反转
- 条件：实体较小，位于当日区间上端；下影线较长；上影线很短或没有
- 要点：必须出现在下跌之后或支撑附近才更有意义
- 失效：后续跌破锤子线低点

**上吊线 (Hanging Man)**
- 含义：上升趋势后的潜在看跌警告
- 条件：形状与锤子线相同，但位置在上涨之后
- 要点：需要次日或后续看跌确认
- 失效：价格继续强势上破，且无回落确认

**倒锤子线 (Inverted Hammer)**
- 含义：下降趋势后的潜在看涨警告
- 条件：实体较小，位于区间下端；上影线较长；下影线很短或没有
- 要点：仅是警告，必须等待确认

**流星线 (Shooting Star)**
- 含义：上升趋势后的潜在看跌反转
- 条件：实体较小，位于区间下端；上影线较长；下影线很短或没有
- 要点：高位、阻力位出现时更有效

**十字星 (Doji)**
- 含义：犹豫、平衡改变、潜在转折警告
- 条件：开收盘相同或非常接近
- 要点：出现在成熟趋势末端更重要；出现在震荡中部意义较弱

### 双根形态

**吞没形态 (Engulfing Pattern)**
- 看涨吞没：下跌后出现，后一根实体包住前一根实体
- 看跌吞没：上涨后出现，后一根实体包住前一根实体
- 要点：属于较强反转信号，位置越关键越有效

**刺透形态 (Piercing Pattern)**
- 含义：下降趋势后的看涨反转信号
- 条件：先长阴，后低开上收，并深入前一根实体内部，最好超过前实体一半

**乌云盖顶 (Dark Cloud Cover)**
- 含义：上升趋势后的看跌反转信号
- 条件：先长阳，后高开低收，并深入前一根实体内部，最好跌入前实体一半以下

**孕线 (Harami)**
- 含义：行情动能收缩，可能反转
- 条件：后一根较小实体被前一根较大实体包含
- 要点：通常弱于吞没；若第二根为十字星，则更强

**平头顶部 / 平头底部 (Tweezer Top / Bottom)**
- 含义：同一高点或低点附近出现重复拒绝
- 要点：与水平阻力 / 支撑配合时更有效

### 三根及复合形态

**启明星 (Morning Star)**
- 含义：下降趋势后的看涨反转
- 条件：长阴 → 小实体/星线 → 长阳，且第三根明显收回到第一根实体内部

**黄昏星 (Evening Star)**
- 含义：上升趋势后的看跌反转
- 条件：长阳 → 小实体/星线 → 长阴，且第三根明显收回到第一根实体内部

**十字启明星 / 十字黄昏星 (Morning Doji Star / Evening Doji Star)**
- 含义：比普通星形更强的转折警告
- 条件：中间那根为十字星

**弃婴顶部 / 弃婴底部 (Abandoned Baby)**
- 含义：强烈但少见的反转信号
- 条件：中间十字星与前后 K 线之间都存在窗口，彼此影线不接触

**三白兵 (Three White Soldiers)**
- 含义：下跌后或底部区域的强势上攻
- 要点：若已大幅上涨后才出现，反而需警惕衰竭

**三只乌鸦 (Three Black Crows)**
- 含义：上涨后或高位区域的强势转弱

**上升三法 / 下降三法 (Rising / Falling Three Methods)**
- 含义：趋势中的整理后延续
- 要点：这是延续形态，不是反转形态

**塔形顶 / 塔形底 (Tower Top / Bottom)**
- 含义：由持续推进转为停滞，再转为急促反向运动的复合反转

## Step 4: 判断确认与失效

蜡烛图最重要的不是“像不像”，而是**有没有确认**。

优先确认：
- 下一根 K 线是否顺着形态方向发展
- 收盘价是否站上 / 跌破关键位
- 支撑或阻力是否被守住或击穿
- 跳空窗口是否被回补或守住
- 是否存在量能放大、动量背离、多周期共振

常见原则：
- 锤子线、倒锤子线、上吊线、流星线通常需要下一根 K 线确认
- 十字星本身多是警告，不应直接当作执行信号
- 吞没、启明星、黄昏星、弃婴等复合形态通常更强，但仍需结合位置判断

### 明确失效条件

每次都要写清楚：
- 哪个价格被突破后，原判断失效
- 如果失效，下一种更可能的情景是什么

如果用户没有给出足够完整的图表，不要虚构精确失效位。

## Step 5: 结合西方技术工具

按照书中的方法，蜡烛图最好与其他技术工具配合，而不是孤立使用。

建议结合：
- 水平支撑 / 阻力
- 趋势线与通道
- 均线
- RSI / MACD 背离
- 成交量
- 回撤位与密集区
- 多周期分析

原则：**中等质量的蜡烛图 + 关键位置 + 其它工具验证，往往强于单独一个“ textbook ”形态。**

## Step 5A: 书本式进场策略 (`Entry Playbook`)

以下进场策略严格遵循《日本蜡烛图技术》的核心原则：**趋势 + 位置 + 形态 + 确认**。

### 看涨进场 (`Bullish Entries`)

**锤子线 (`Hammer`)**
- 场景：下降趋势后、支撑位、前低附近
- 进场：优先等下一根 K 线向上确认后再买入
- 确认：收盘站上锤子线实体上沿，或上破锤子线高点
- 失效：跌破锤子线低点

**倒锤子线 (`Inverted Hammer`)**
- 场景：下降趋势后低位出现
- 进场：不能直接买，必须等待后续看涨确认
- 确认：后续阳线或上破倒锤子线高点
- 失效：跌破倒锤子线低点

**看涨吞没 (`Bullish Engulfing`)**
- 场景：下跌后、支撑区、重要低点附近
- 进场：形态成立后可积极考虑；更稳健者等后续继续走强
- 强化：第二根实体越大、吞没越充分、位置越关键越好
- 失效：跌回吞没组合低点下方

**刺透形态 (`Piercing Pattern`)**
- 场景：下降趋势后
- 进场：第二根深入前一根阴线实体一半以上时可考虑
- 确认：次日继续上行更佳
- 失效：跌破组合低点

**启明星 (`Morning Star`) / 十字启明星 (`Morning Doji Star`)**
- 场景：持续下跌后、支撑区、恐慌抛售末端
- 进场：第三根长阳确认后买入
- 强化：中间为十字星、第三根收回更深
- 失效：跌破整个三根组合低点

**看涨孕线 (`Bullish Harami`) / 十字孕线 (`Bullish Harami Cross`)**
- 场景：下跌后动能衰减
- 进场：通常弱于吞没，宜等后续向上确认
- 强化：第二根为十字星
- 失效：跌破母体大阴线低点或组合低点

**平头底 (`Tweezer Bottom`)**
- 场景：同一低点区域被两次拒绝下破
- 进场：确认支撑有效后买入
- 强化：与历史支撑、窗口下沿重合
- 失效：支撑被有效跌破

**弃婴底 (`Abandoned Baby Bottom`)**
- 场景：急跌末端，中间十字星与前后 K 线均有窗口
- 进场：第三根确认后可积极看待
- 失效：跌破组合低点

**三白兵 (`Three White Soldiers`)**
- 场景：底部区域或下跌后强势转多
- 进场：确认不是高位衰竭后，可作为趋势反转后的跟随买点
- 风险：若出现在已大涨后的高位，反而需警惕衰竭
- 失效：跌回结构关键支撑下

**塔形底 (`Tower Bottom`)**
- 场景：下跌后急跌 → 止跌横盘 → 快速反攻
- 进场：反攻段确认后买入
- 失效：重新跌回底部平台下方

### 看跌进场 (`Bearish Entries`)

**上吊线 (`Hanging Man`)**
- 场景：上涨后高位、阻力区
- 进场：不能只看单根，需次日或后续走弱确认
- 确认：跌破上吊线低点、后续收阴
- 失效：价格继续上破并站稳

**流星线 (`Shooting Star`)**
- 场景：上涨后、阻力位、高位冲高失败
- 进场：等待下一根向下确认
- 确认：跌破流星线低点或后续阴线延续
- 失效：重新上破流星线高点

**看跌吞没 (`Bearish Engulfing`)**
- 场景：上涨趋势后、高位或阻力区
- 进场：形态成立后可视为较强转弱信号
- 确认：后续继续走弱更稳健
- 失效：重新站回吞没组合高点

**乌云盖顶 (`Dark Cloud Cover`)**
- 场景：上涨后
- 进场：第二根跌回前阳线实体一半以下时可考虑
- 确认：后续阴线延续
- 失效：再度站上组合高点

**黄昏星 (`Evening Star`) / 十字黄昏星 (`Evening Doji Star`)**
- 场景：上涨趋势末端、高位阻力
- 进场：第三根长阴确认后执行
- 强化：中间为十字星、第三根跌入更深
- 失效：重新上破三根组合高点

**看跌孕线 (`Bearish Harami`) / 十字孕线 (`Bearish Harami Cross`)**
- 场景：上涨后动能减弱
- 进场：通常弱于吞没，宜等后续转弱确认
- 失效：上破母体大阳线高点

**平头顶 (`Tweezer Top`)**
- 场景：同一高点区域两次受阻
- 进场：确认阻力有效后执行
- 强化：与前高、通道上沿、窗口上沿重合
- 失效：有效突破阻力

**弃婴顶 (`Abandoned Baby Top`)**
- 场景：急涨末端，中间十字星与前后 K 线均有窗口
- 进场：第三根确认后可积极看待反转
- 失效：重新站上组合高点

**三只乌鸦 (`Three Black Crows`)**
- 场景：高位或上涨后转弱
- 进场：可作为反转后的跟随卖点或做空点
- 风险：若已大跌很深后才出现，需防追空
- 失效：重新站回结构上方

**塔形顶 (`Tower Top`)**
- 场景：上涨后急冲 → 停滞 → 快速反向下跌
- 进场：反转段确认后执行
- 失效：重新突破顶部平台

### 延续型进场 (`Continuation Entries`)

**上升三法 (`Rising Three Methods`)**
- 场景：上升趋势中的短暂整理
- 进场：整理结束、向上恢复时顺势买入
- 失效：跌破母体大阳线低点或趋势支撑

**下降三法 (`Falling Three Methods`)**
- 场景：下降趋势中的短暂反弹整理
- 进场：向下恢复时顺势卖出或做空
- 失效：上破母体大阴线高点

## Step 5B: 书本式离场策略 (`Exit Playbook`)

书中对离场的核心不是固定公式，而是：**确认失败、关键位失守、反向信号出现时退出**。

### 核心离场原则

**形态失效离场**
- 看涨交易：跌破锤子线、启明星、吞没、刺透等组合低点时离场
- 看跌交易：上破流星线、黄昏星、看跌吞没等组合高点时离场

**确认失败离场**
- 入场后没有朝预期方向发展，应降低主观执念
- 例如：锤子线后没有上行确认；上吊线后市场不跌反涨

**关键阻力 / 支撑到位减仓**
- 多头在前高、阻力线、窗口上沿、密集区上沿附近减仓
- 空头在前低、支撑线、窗口下沿、密集区下沿附近减仓

**反向蜡烛信号离场**
- 多单持有时，若高位出现流星线、黄昏星、看跌吞没、乌云盖顶、十字星警告，应考虑减仓或退出
- 空单持有时，若低位出现锤子线、启明星、看涨吞没、刺透形态等，应考虑减仓或退出

**窗口 (`Window / Gap`) 失效离场**
- 上涨窗口通常构成支撑；若被回补并失守，多头逻辑削弱
- 下跌窗口通常构成阻力；若被突破，空头逻辑削弱

**支撑 / 阻力角色转换离场**
- 原阻力突破后应转为支撑；原支撑跌破后应转为阻力
- 若价格重新失守“本应守住的位置”，说明原交易逻辑被破坏

**趋势反转证据出现离场**
- 持有顺势仓位时，若出现一组完整反向反转结构，而非单根噪音，宜离场

**分批止盈离场**
- 第一目标：最近反向摆动高低点
- 第二目标：更高一级阻力或支撑
- 若走势延续，可保留部分仓位跟随趋势

### 执行模板

**激进方案**
- 复合形态刚形成就执行，适用于吞没、启明星、黄昏星、弃婴等较强结构

**保守方案**
- 等下一根 K 线确认后再执行，适用于锤子线、倒锤子线、上吊线、流星线、十字星

**位置优先**
- 仅当形态出现在关键位时才赋予较高权重

**多工具共振**
- 蜡烛图 + 支撑阻力 + 趋势线 + 窗口 + 均线 + 成交量，共振越多越可信

## Step 5C: 统一执行字段 (`Execution Fields`)

在输出任何形态分析时，优先补齐以下字段；若图表信息不足，应明确写“无法精确判断”，不要虚构。

- **适用位置 (`Best Context`)**：该形态最有意义的位置，例如下降末端、上升末端、支撑位、阻力位、窗口附近、区间边缘
- **确认方式 (`Confirmation`)**：需要哪种后续价格行为才算确认，例如上破高点、跌破低点、下一根收阳/收阴、站回/跌破关键位
- **常见误判 (`Common Trap`)**：该形态最常见的误用场景，例如区间中部、没有趋势背景、没有确认、已经大幅运行后才出现
- **止损锚点 (`Invalidation / Stop Anchor`)**：失效位通常应放在哪里，例如单根低点/高点、组合低点/高点、母体 K 线高低点、窗口边界
- **目标位锚点 (`Target Anchor`)**：优先看哪些目标，例如前高/前低、最近摆动点、窗口、趋势线、通道边界、下一层支撑阻力

### 各形态字段提示

**锤子线 / 上吊线 / 倒锤子线 / 流星线**
- 适用位置：趋势末端 + 关键位
- 确认方式：下一根 K 线向预期方向发展
- 常见误判：只因“长得像”就交易；出现在震荡中部
- 止损锚点：单根 K 线高点或低点之外
- 目标位锚点：最近反向摆动高低点、前高前低、最近阻力支撑

**吞没 / 刺透 / 乌云盖顶 / 孕线**
- 适用位置：趋势末端或关键支撑阻力区
- 确认方式：后续继续向形态方向推进
- 常见误判：忽略前面是否真的存在趋势；忽略实体大小与位置
- 止损锚点：双根组合高点或低点；孕线也可参考母体 K 线边界
- 目标位锚点：前高前低、窗口、密集成交区边缘

**启明星 / 黄昏星 / 弃婴 / 塔形顶底**
- 适用位置：趋势成熟末端、恐慌或狂热后的反向转折区
- 确认方式：第三根完成并明显收回前一推动段实体内部
- 常见误判：第三根力度不够却过早认定反转完成
- 止损锚点：整个三根或复合结构的高点/低点
- 目标位锚点：第一目标看最近反向摆动点，第二目标看更高一级阻力或支撑

**三白兵 / 三只乌鸦**
- 适用位置：底部转强或顶部转弱
- 确认方式：不是孤立爆发，而是结构性持续推进
- 常见误判：在大幅上涨后看到三白兵继续追多；在大幅下跌后看到三乌鸦继续追空
- 止损锚点：三根结构的中枢或起始 K 线高低点
- 目标位锚点：前期密集区、前高前低、趋势通道边界

**上升三法 / 下降三法**
- 适用位置：已经存在明确趋势的中继整理
- 确认方式：母体趋势恢复，突破整理结构
- 常见误判：把它当作反转，而不是延续
- 止损锚点：母体 K 线低点或高点、整理区边界
- 目标位锚点：顺趋势下一阻力或支撑、通道边界、前波段延伸位

## 可信度分级

给出 `低 / 中 / 高` 三档可信度，并说明原因。

### 高可信度
同时满足多数条件：
- 前置趋势清晰
- 形态出现在关键位置
- 后续确认明确
- 高一级周期不冲突
- 有额外工具验证

### 中可信度
满足部分条件，但仍存在缺口：
- 形态较清楚
- 位置尚可
- 确认一般或周期有轻微冲突

### 低可信度
出现以下任一情况时倾向低可信度：
- 只有局部截图或信息残缺
- 形态出现在区间中部
- 趋势不清晰
- 没有确认
- 高一级周期明显冲突

## 何时拒绝过度解读

下列情况下，必须主动降级结论：
- 只有一两根 K 线，没有上下文
- 图像太小，无法看清价格刻度或周期
- 不知道是复权还是不复权
- 盘前盘后数据混入，但用户未说明
- 用户要求“只根据这根 K 线直接判断涨跌”

推荐表达：
- “这是一个**候选形态**，但还不能单独确认。”
- “从当前截图看，**更像警告信号而非执行信号**。”
- “如果不能补充更大周期图，这个判断只能维持中低可信度。”

## 美股 Trade Idea 模板

当用户明确要 `美股 trade idea`，且希望**以蜡烛图为主导**来组织观点时，按下面顺序输出：

1. 先给出 `周线 → 日线` 趋势背景
2. 再说明关键蜡烛图形态及其位置
3. 然后写清 `确认位 / 失效位 / 止损位 / 目标位`
4. 最后补充基本面或事件催化，但**不要让基本面覆盖 K 线结论**

### 模板一：回调企稳型做多

适用场景：
- 美股强势股处于上升趋势中
- 日线回调到前支撑、上升趋势线、跳空缺口上沿或关键均线附近
- 在该位置出现 `锤子线 (Hammer)`、`看涨吞没 (Bullish Engulfing)`、`启明星 (Morning Star)`

输出重点：
- 这是 `顺势回调后的看涨候选`，不是抄底逆转
- 只有在后续站回前一根 K 线高点、或次日继续上攻时才算确认
- 失效通常是跌破锤子线低点、启明星结构低点、或关键支撑区

一句话表达示例：
- `某美股 — 偏多：日线回调到支撑区后出现锤子线，若次日上破锤子高点，可视为顺势低风险做多触发。`

### 模板二：平台突破型做多

适用场景：
- 美股经过 `3-8` 周横盘整理
- 突破前夕出现小实体收敛、十字星、或多根短实体蓄势
- 突破日出现强阳线，或突破后回踩时出现 `看涨吞没` / `刺透形态 (Piercing Pattern)`

输出重点：
- 重点不是“突破日长阳”本身，而是突破前的压缩与突破后的确认
- 若突破后立刻被拉回平台内，则视为 `假突破 (False Breakout)` 风险上升
- 第一目标通常看平台高度投射或前高区域

一句话表达示例：
- `某美股 — 偏多：平台整理末端出现蓄势 K 线，若放量突破并守住平台上沿，属于延续型做多结构。`

### 模板三：高位反转型做空

适用场景：
- 美股前期已有明显涨幅
- 价格来到前高、整数关口、跳空缺口压力或长期阻力区
- 此处出现 `流星线 (Shooting Star)`、`看跌吞没 (Bearish Engulfing)`、`黄昏星 (Evening Star)`、`乌云盖顶 (Dark Cloud Cover)`

输出重点：
- 先确认是不是高位、是不是上涨后，而不是只看形态名字
- 若次日继续下破关键低点，则反转概率提升
- 若形态后价格反而强势站上压力位，原看空判断失效

一句话表达示例：
- `某美股 — 偏空：高位阻力区出现流星线，若后续跌破该 K 线低点，可视为上攻失败后的短线做空信号。`

### 模板四：假突破反手型做空

适用场景：
- 美股刚突破前高或平台，但未能站稳
- 突破后的 1-3 根 K 线中出现 `上吊线 (Hanging Man)`、`流星线`、`看跌吞没`
- 随后价格重新跌回原整理区间

输出重点：
- 这是典型的 `bull trap / 假突破`
- 真正可执行的信号，往往不是第一根冲高 K 线，而是 `跌回平台内` 的确认动作
- 第一目标通常看平台中轴，第二目标看平台下沿

一句话表达示例：
- `某美股 — 偏空：前高突破失败后回落，并出现看跌吞没，若跌回原平台内，可按假突破反手思路处理。`

### 模板五：财报后 K 线确认型

适用场景：
- 美股财报、指引、产品发布后出现大幅跳空
- 用户希望判断“该不该追”“是不是反转”“能不能做第二波”

输出重点：
- 先判断跳空是 `突破缺口 (Breakaway Gap)`、`衰竭缺口 (Exhaustion Gap)`，还是普通情绪缺口
- 若跳空后在高位收出 `十字星`、`流星线`、`黄昏星`，要警惕利好兑现
- 若跳空后回踩缺口上沿并出现 `锤子线` / `看涨吞没`，则更偏向二次上攻

一句话表达示例：
- `某美股 — 观察偏多：财报跳空后若回踩缺口上沿并出现看涨吞没，说明跳空更可能是突破缺口而非一次性脉冲。`

## 美股 Trade Idea 输出附加要求

当用户要你直接给出 trade idea，而不是单纯识别形态时，额外补齐以下内容：

- `方向`：做多 / 做空 / 观察
- `周期`：日线为主，必要时辅以周线
- `形态`：明确写出中英术语
- `确认位`：什么价格动作算成立
- `失效位`：跌破 / 站回哪个位置视为判断失效
- `止损位`：与失效位一致或更保守
- `第一目标位`：前高、前低、缺口、平台边界
- `第二目标位`：趋势延伸、量度升幅 / 跌幅
- `可信度`：低 / 中 / 高，并说明原因

如果没有具体图表或 OHLC，不要伪造数值；应输出为：
- `确认位：需等日线收盘上破最近形态高点`
- `失效位：若跌破最近形态低点则失效`
- `目标位：先看前高 / 前低或平台边界`

## 重要提醒

- 不要把形态名称当成结论
- 不要忽略趋势背景
- 不要把十字星一律当反转
- 不要在缺少上下文时给出过度精确的交易位
- 不要忽略窗口 (`Window / Gap`) 的支撑阻力作用
- 不要用低周期信号直接对抗强高周期趋势，而不说明这是逆势交易

最终目标不是回答“这是什么形态”，而是回答：
- 它出现在什么趋势里
- 它出现在什么位置上
- 是否已经确认
- 哪个价位失效
- 如果判断错了，下一步应该怎么办
